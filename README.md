# Electronic Dice System

## Project Overview
The Electronic Dice System is a Digital Logic Design project that demonstrates the working of a sequential counter using the NE555 Timer IC and CD4017 Decade Counter IC.

The circuit uses six LEDs to represent the numbers of a dice. The NE555 Timer generates clock pulses, while the CD4017 counts these pulses and activates the LEDs sequentially.

**Note:** This circuit demonstrates a repeating LED sequence and does not generate truly random dice numbers.

## Components Used
- NE555 Timer IC
- CD4017BE Decade Counter IC
- 6 Red LEDs
- Resistors
- Capacitor
- Push Button / Switch
- 5V Power Supply
- Breadboard
- Jumper Wires

## Working Principle
1. The NE555 Timer generates clock pulses.
2. The CD4017 receives these clock pulses.
3. The counter activates its output pins sequentially.
4. Six LEDs turn ON one after another.
5. The Q6 output resets the counter to Q0, and the sequence repeats.
